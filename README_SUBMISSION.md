The full high-level and low-level design is in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Current implementation: authentication and RBAC

The WebSocket endpoint is available at `ws://localhost:8000/ws/chat` and expects
the required first frame:

```json
{"type": "auth", "token": "<jwt>"}
```

`app.auth.jwt.decode_access_token` verifies HS256 signatures, expiry, issued-at time,
and every authorization claim before creating an immutable `AuthenticatedUser`.
Only this verified object is passed beyond the authentication boundary. Invalid,
expired, malformed, or incomplete tokens receive `auth_failed` and the socket is
closed with policy-violation code `1008`.

The RBAC policy is centralized in `AccessScope`. It allows a user to retrieve HR
content plus their own department, with `access_level <= user.level`. The data
layer will pass `user.access_scope.qdrant_filter()` directly to the Qdrant query,
which ensures unauthorized chunks are never returned for application-side filtering.

## Run ingestion

Scanned PDFs (`exec/strategic_plan.pdf`) need the Tesseract binary, not just
the `pytesseract` wheel:

```bash
brew install tesseract   # macOS; or apt install tesseract-ocr
```

Stop any process using the embedded store (the chat server holds
`./app/qdrant_db/.lock` once retrieval has run), then rebuild `policy_docs`:

```bash
python -m app.data.ingestion --source-dir app/docs --qdrant-path ./app/qdrant_db --recreate-collection
```

`--qdrant-path` always uses the local embedded database. Extraction and
chunking run first; a missing PDF or OCR failure aborts before the collection
is dropped.

## Chunking strategy

Chunks follow document headings, not a sliding window across the whole file.

- Parser keeps heading lines intact and splits numbered headings that OCR/PDF
  layout glued onto the next sentence (`2. Membership The committee...`).
- Chunker starts a new chunk at each `N. Title` heading and each `Priority N:`
  line. The title/preamble is its own opening section.
- Overlap is used only when a single section exceeds ~450 words; it never
  crosses a heading. Continuation chunks repeat the heading.
- Default 450-word size / 75-word overlap is a fallback for unheaded text and
  oversized sections. These policy PDFs are short, so most sections are one
  chunk.

## Run the auth layer

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python3 mint_tokens.py
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/` and paste a token generated by `mint_tokens.py`.
The supplied `test_client.html` is served by the API, so it uses the same local
origin and its default WebSocket URL. Authentication succeeds now; chat requests
intentionally return an error until the orchestration layer is added.
